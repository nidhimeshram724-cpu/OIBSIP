# EDA on Retail Sales Data

## OASIS INFOBYTE SIP Internship

**Track:** Data Analytics  
**Level:** Level 1  
**Task:** Exploratory Data Analysis (EDA) on Retail Sales Data

## Project Overview

The goal of this project is to analyze retail sales data using Python and discover useful patterns, sales trends, and customer insights. Exploratory Data Analysis (EDA) helps us understand the dataset and make data-driven business recommendations.

## Objectives

- Understand and inspect the retail sales dataset.
- Identify missing values and examine data types.
- Calculate descriptive statistics such as mean, median, mode, and standard deviation.
- Analyze monthly and quarterly sales trends.
- Explore customer age groups and gender distribution.
- Identify the top 10 best-selling products.
- Analyze revenue by product category.
- Explore relationships between numerical variables using a correlation heatmap.
- Provide actionable business recommendations.

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## Project Workflow

1. Load and inspect the dataset.
2. Clean and prepare the data.
3. Perform descriptive statistical analysis.
4. Create visualizations to identify sales and customer trends.
5. Interpret the results and write observations.
6. Provide business recommendations based on the findings.

## Expected Deliverables

- Python notebook containing the analysis.
- Visualizations and observations.
- Summary of key findings.
- At least three actionable business recommendations.
